# Aurora Shop - Projet E-Commerce Thème Boréal

## 🧑‍💻 Contexte du Projet

[cite_start]Ce dépôt est l'initialisation du devoir de groupe Git/GitHub[cite: 1, 4]. [cite_start]L'objectif est de simuler un flux de travail professionnel incluant l'utilisation de branches [cite: 14][cite_start], la résolution de conflits[cite: 16], et la collaboration.

### 🌐 Technologies

* **Front-end** : HTML5, CSS3, JavaScript
* **Framework** : Bootstrap 5
* **Thème** : Couleurs Boréales (Bleu Nuit, Vert-Bleu, Violet)

### 📄 Structure du Dépôt (7 Fichiers Requis)

| Fichier | Rôle |
| :--- | :--- |
| `index.html` | Page d'accueil principale |
| `page2.html` | Page secondaire (Catalogue simple) |
| `styles.css` | Styles CSS personnalisés (Couleurs de base) |
| `components.css` | Styles CSS modifiant les composants Bootstrap |
| `script.js` | Logique JavaScript (Rend la page dynamique) |
| `data.json` | Fichier de données au format JSON |
| `README.md` | Documentation du projet (ce fichier) |

## 🚀 Étapes pour les Collaborateurs

1.  **Cloner le projet** (en utilisant l'URL SSH) :
    ```bash
    git clone git@github.com:Lrigobert/ProjetDeDevoirGit.git
    ```## Lrigobert: J'ai modifié ce fichier (Conflit)
2.  **Créer une nouvelle branche** pour vos travaux (IMPORTANT !) :
    ```bash
    git checkout -b ma-branche-MonNom
    ```
3.  **Effectuer au moins 3 commits** [cite: 14] (incluant le commit de conflit) [cite: 16].

## 3. Déploiement et Test Final (Chef/Initiateur)

**Veuillez suivre ces étapes scrupuleusement :**

1.  **Copiez** le contenu de chaque fichier ci-dessus dans le fichier correspondant dans votre dossier `ProjetDeDevoirGit`.
2.  **Ouvrez le fichier `index.html` dans votre navigateur** pour vous assurer que le rendu est professionnel et attrayant.
3.  **Dans votre terminal MINGW64**, naviguez dans le dossier `ProjetDeDevoirGit` et exécutez le *push* final :

    ```bash
    git add .
    git commit -m "Déploiement final du projet E-Commerce Thème Boréal avec 7 fichiers"
    git push origin main
    ```

Une fois que ce *push* est réussi, la base de votre projet est prête et vous pouvez passer à l'invitation des membres de votre groupe. **Confirmez le succès du `git push` !**
